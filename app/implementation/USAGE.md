# 使用指南

## 网站与文件

在需要留底的网站开启权限。设置可控制拖放、页面路径和标题；来源地址会移除查询参数与片段。暂停自动留底后仍可手动保存。

保存后可取消网页上传，已保存副本会保留。网站可能进一步处理附件，提交状态由你按实际结果标记。

支持顶层页面的标准文件输入与开放 Shadow DOM。目录、iframe、封闭 Shadow DOM、自定义非标准上传控件、浏览器内部页和无痕窗口暂不支持。自动留底默认跳过 `.env` 和常见密钥文件名，排除规则可在设置中修改。

单文件超过 50 MiB 时只记录文件信息；超过 100 个文件或 200 MiB 的批次会被拒绝。资料库上限最高 5 GiB，实际空间受磁盘余量限制。置顶影响检索，原件会一直保留至手动删除。

## 预览与比较

文本预览上限为 2 MiB，小文本比较上限为 1 MiB。HTML 与 SVG 按文本显示。PDF 超过 500 页、加密或渲染超时会提供原件下载。Office 等其他格式也可下载后查看。

## 备份与恢复

在「备份与恢复」导出全部记录，或在列表中选定记录后导出。大备份会拆分为可分别恢复的 ZIP。备份包含文件和记录，采用未加密格式。

恢复时选择 ZIP，检查导入数量后确认。重复记录会跳过并保留本机的新备注；相同 ID 的内容冲突会阻止导入。站点授权沿用本机设置，新安装需要重新开启网站权限。

更新扩展前先备份，再覆盖原文件夹并重新加载。保持路径和扩展 ID 可继续使用原资料库。

## 数据与兼容

内容存储在当前浏览器配置的 IndexedDB，运行资源随扩展打包。协议、主机和端口共同确定站点范围；Chrome 的主机授权可能覆盖同主机的多个端口，应用会额外检查端口。关闭路径和标题可减少来源信息的保存。

已在 macOS Chromium 153 实测，Linux GitHub CI 完成无界面回归。Chrome 120 起可安装；旧版 Chrome、Windows 和具体业务网站需另行确认。完整执行范围见 [测试报告](TEST_EVIDENCE.md)。
